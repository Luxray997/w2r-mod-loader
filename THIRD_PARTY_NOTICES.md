# Third-party notices

## wc2r-plus

wc2r-plus is by Luxray997 (MIT, license below). Substantial parts of this project are ports of
its C++ to Rust, keeping its constants, offsets, wire formats and behaviour. The ports follow
wc2r-plus 1.1.0 (commit `95ed7f1`, 2026-10-02), including its chat channel colour settings and its
fix for non-ASCII map paths:

- `crates/chat-plugin` (`w2r-chat`): the whole in-match chat plugin, a port of `chat.cpp`
  (`src/plugin.rs`, `src/plugin/hud.rs`, `src/model.rs`; spec in `docs/chat-plugin.md`), including
  the customizable `[Team]`, `[All]` and `[Allies]` colours (`LinePalette`, `hex_colour`). The plugin
  is also published from the `w2r-plugins` repository, with this notice in its `LICENSE`.
- `crates/w2r-core`, host basics: the `version.dll` proxy (`src/proxy.rs`), the build guard and
  its signature table (`src/build_guard.rs`, `src/target/signatures.rs`, generated by
  `tools/gen_signatures.py`), the game symbol table (`src/target/symbols.rs`, generated by
  `tools/gen_symbols.py`), the log limits (`src/log.rs`), the file layout under Saved Games
  (`src/paths.rs`) and the main-thread frame hook (`src/frame.rs`).
- `crates/w2r-core`, lobby and peer features: the lobby handshake (`src/handshake.rs`), map
  download and sharing (`src/mapname.rs`, `mapwire.rs`, `maplimits.rs`, `pudvalidate.rs`,
  `downloadhost.rs`, `downloadclient.rs`, `mapstore.rs`, `mapindex.rs`, `maproles.rs`,
  `mapdownload.rs`), the Create Multiplayer Game screen and map browser (`src/screenkit.rs`,
  `createscreen.rs`, `mapbrowser.rs`, `mapsearchcache.rs`, `pud.rs`, `mappreview.rs`,
  `previewdraw.rs`, `browserview.rs`), the multiplayer lobby screen (`src/lobbyscreen.rs`,
  `lobbylayout.rs`, including the crown image from `crown_image.h`) and the settings screen
  layout (`src/options.rs`).
- `crates/w2r-core/src/gamepath.rs`: how game path strings are read (UTF-8, else the ANSI code
  page), after `map_index::FromGamePath`. The search-index changes in `mapbrowser.rs` /
  `browserview.rs` respond to the same release's search freeze fix but do not port its index.

Other files in `w2r-core` cite wc2r-plus as the behavioural reference; where they do, the
comment says so.
