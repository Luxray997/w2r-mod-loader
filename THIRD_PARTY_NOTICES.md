## wc2r-plus

Parts of `crates/w2r-core` are ported from wc2r-plus (commit `61e37d5`): the `version.dll`
proxy (`src/proxy.rs`), the build guard and its signature table (`src/build_guard.rs`,
`src/target/signatures.rs`, generated by `tools/gen_signatures.py`), the game symbol table
(`src/target/symbols.rs`, generated by `tools/gen_symbols.py`), the log limits (`src/log.rs`),
the file layout under Saved Games (`src/paths.rs`) and the main-thread frame hook
(`src/frame.rs`).
