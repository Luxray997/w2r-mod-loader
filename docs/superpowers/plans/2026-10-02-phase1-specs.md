# Phase 1 Specs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the four Phase 1 specs (ABI + C header, manifest, signed index, load policy) with executable test vectors, so Phase 2 and Phase 4 can be built from them.

**Architecture:** Each spec is a markdown doc in `docs/`. For the manifest, index and simulation fingerprint, a small Python *reference implementation* (`tools/w2r_spec/`) encodes the rules and is checked against JSON test vectors in `docs/vectors/`. The vectors are generated by deterministic scripts whose expected results are written by hand per case, never derived from the validator. The C header is checked by compiling a layout test as C11, C++17 and (when available) 32-bit. The Python code is a spec aid and vector generator, not product code; Phase 4 re-implements the rules in Rust against the same vectors.

**Tech Stack:** Markdown, Python 3.12 (stdlib `unittest`, `cryptography` for ed25519), C11 header checked with gcc/g++.

**Spec:** `docs/superpowers/specs/2026-10-02-phase1-specs-design.md`

## Global Constraints

- Manifest format is JSON (`plugin.json`); `schema` integer is 1; unknown fields rejected; unknown schema versions refused.
- Manifest size limit 64 KiB; index size limit 8 MiB; package size limit 64 MiB.
- Plugin id regex `[a-z0-9][a-z0-9-]{1,62}[a-z0-9]`; version is SemVer 2.0.0 without build metadata.
- Capabilities requiring approval: `game.read`, `chat.read`, `chat.write`, `net.send`, `hooks.raw`. `log`, `settings`, `ui`, `fs.data` are implicit and are NOT valid manifest entries.
- Index signature: ed25519, minisign file format, algorithm `ED` (BLAKE2b-512 prehash). Legacy `Ed` is refused.
- Index freshness: `serial` must not be lower than the cached serial (equal is accepted); `expires` must be in the future.
- Peer messages: envelope `0xE7 'W' '2' 'R'`, subsystem byte, then payload; whole message at most 989 bytes. Plugin messages use subsystem `'P'` + 4-byte tag; first-party subsystems `'H'`, `'M'`, `'L'` are reserved.
- Simulation fingerprint: first 4 bytes of SHA-256 over the id-sorted `(id, version, dll-sha256)` list of enabled `affects_simulation` plugins; all-zero when there are none.
- The in-game host performs no network I/O. All peer-originated data reaching a plugin is bounded and sanitised.
- Calling convention `__cdecl` on 32-bit Windows; fixed-width C types only.
- Capabilities are a consent prompt and guardrail, not a security boundary; every spec that mentions them says so.
- Commits end with the trailer line `Claude-Session: https://claude.ai/code/session_015GrKhNbxr1N7QrzwX3YLE7` (pass it as a second `-m`).

## Review Focus

Failure modes the spec implies that no obvious happy-path test covers (each is pinned by a test in the named task):

1. **JSON smuggling:** duplicate keys, `NaN`, a UTF-8 BOM and absurd nesting depth in manifest/index must be refused, not tolerated (Task 1, Task 2).
2. **Path-shaped identifiers:** `id` or `entry` containing `..`, separators, drive/UNC forms or Windows device names (`CON.dll`) must be refused (Task 1).
3. **Index replay and clock trouble:** a lower `serial`, an expired index, `generated` after `expires`, and an *equal* serial (must be accepted, so a re-fetch does not fail) (Task 2).
4. **Resource abuse:** an oversize index and an index with thousands of plugins or versions must fail fast and bounded (Task 2).
5. **Tag and fingerprint collisions:** duplicate plugin ids in the fingerprint input and two plugin ids with the same 4-byte peer tag (Task 3).

"""Strict JSON parsing shared by the manifest and index reference validators."""
import json


class Reject(Exception):
    def __init__(self, code):
        super().__init__(code)
        self.code = code


def _pairs(pairs):
    out = {}
    for key, value in pairs:
        if key in out:
            raise Reject("duplicate_key")
        out[key] = value
    return out


def _constant(name):
    raise Reject("not_json")


def parse(raw):
    """Parse UTF-8 JSON bytes. Refuses duplicate keys, NaN/Infinity, a BOM and runaway nesting."""
    try:
        return json.loads(
            raw.decode("utf-8"), object_pairs_hook=_pairs, parse_constant=_constant
        )
    except (UnicodeDecodeError, ValueError, RecursionError):
        raise Reject("not_json") from None
```

"""Reference validator for plugin.json (docs/manifest.md). Returns "ok" or a reason code."""
import re

from . import jsonutil

MAX_BYTES = 64 * 1024
FIELDS = {
    "schema", "id", "name", "version", "author", "description", "entry", "abi",
    "game_builds", "capabilities", "affects_simulation", "dependencies",
}
CAPABILITIES = {"game.read", "chat.read", "chat.write", "net.send", "hooks.raw"}
RESERVED_DEVICES = {"CON", "PRN", "AUX", "NUL"} | {"COM%d" % i for i in range(1, 10)} | {
    "LPT%d" % i for i in range(1, 10)
}

ID_RE = re.compile(r"^[a-z0-9][a-z0-9-]{1,62}[a-z0-9]$")
_PRE = r"(0|[1-9][0-9]*|[0-9]*[A-Za-z-][0-9A-Za-z-]*)"
SEMVER_RE = re.compile(
    r"^(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)(-" + _PRE + r"(\." + _PRE + r")*)?$"
)
_BUILD = r"[0-9]{1,5}(?:\.[0-9]{1,5}){3}"
BUILD_RE = re.compile(r"^(" + _BUILD + r")(?:-(" + _BUILD + r"))?$")
ENTRY_RE = re.compile(r"^[A-Za-z0-9_][A-Za-z0-9_.-]{0,59}\.dll$")
_CMP = r"(?:>=|<=|>|<|=)[0-9]+\.[0-9]+\.[0-9]+"
REQ_RE = re.compile(r"^" + _CMP + r"(?:," + _CMP + r"){0,3}$")

REASONS = {
    "too_large", "not_json", "duplicate_key", "not_object", "unknown_field", "missing_field",
    "bad_schema", "bad_id", "bad_type", "bad_string", "too_long", "bad_version", "bad_entry",
    "bad_abi", "bad_build", "bad_capability", "bad_dependency",
}


def _is_int(v):
    return isinstance(v, int) and not isinstance(v, bool)


def _text(v, max_bytes):
    if not isinstance(v, str):
        return "bad_type"
    if not v or any(ord(c) < 0x20 or ord(c) == 0x7F for c in v):
        return "bad_string"
    if len(v.encode("utf-8")) > max_bytes:
        return "too_long"
    return None


def _build_tuple(s):
    return tuple(int(p) for p in s.split("."))


def _builds_ok(builds):
    if not isinstance(builds, list):
        return "bad_type"
    if not 1 <= len(builds) <= 16:
        return "bad_build"
    for b in builds:
        m = BUILD_RE.match(b) if isinstance(b, str) else None
        if not m:
            return "bad_build"
        if m.group(2) and _build_tuple(m.group(1)) > _build_tuple(m.group(2)):
            return "bad_build"
    return None


def _entry_ok(e):
    if not isinstance(e, str) or not ENTRY_RE.match(e) or ".." in e:
        return False
    return e.split(".")[0].upper() not in RESERVED_DEVICES


def _deps_ok(deps, own_id):
    if not isinstance(deps, list):
        return "bad_type"
    if len(deps) > 16:
        return "bad_dependency"
    seen = set()
    for d in deps:
        if not isinstance(d, dict) or set(d) != {"id", "version_req"}:
            return "bad_dependency"
        did, req = d["id"], d["version_req"]
        if not isinstance(did, str) or not ID_RE.match(did) or did == own_id or did in seen:
            return "bad_dependency"
        if not isinstance(req, str) or not REQ_RE.match(req):
            return "bad_dependency"
        seen.add(did)
    return None


def _caps_ok(caps):
    if not isinstance(caps, list):
        return "bad_type"
    if not all(isinstance(c, str) and c in CAPABILITIES for c in caps):
        return "bad_capability"
    if len(set(caps)) != len(caps):
        return "bad_capability"
    return None


def validate_manifest(raw):
    if len(raw) > MAX_BYTES:
        return "too_large"
    try:
        doc = jsonutil.parse(raw)
    except jsonutil.Reject as r:
        return r.code
    if not isinstance(doc, dict):
        return "not_object"
    if set(doc) - FIELDS:
        return "unknown_field"
    if FIELDS - set(doc):
        return "missing_field"
    if not _is_int(doc["schema"]) or doc["schema"] != 1:
        return "bad_schema"
    if not isinstance(doc["id"], str) or not ID_RE.match(doc["id"]):
        return "bad_id"
    for field, limit in (("name", 64), ("author", 64), ("description", 256)):
        err = _text(doc[field], limit)
        if err:
            return err
    if not isinstance(doc["version"], str) or not SEMVER_RE.match(doc["version"]):
        return "bad_version"
    if not _entry_ok(doc["entry"]):
        return "bad_entry"
    if not _is_int(doc["abi"]) or doc["abi"] < 1:
        return "bad_abi"
    err = _builds_ok(doc["game_builds"]) or _caps_ok(doc["capabilities"])
    if err:
        return err
    if not isinstance(doc["affects_simulation"], bool):
        return "bad_type"
    return _deps_ok(doc["dependencies"], doc["id"]) or "ok"
```

"""Minisign-format ed25519 signatures (algorithm "ED": BLAKE2b-512 prehash).

Written from the minisign file format description; no minisign binary was available to cross-check.
Task 5 records that interoperability with the real tool must be verified before the first release.
"""
import base64
import hashlib

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey, Ed25519PublicKey
from cryptography.hazmat.primitives.serialization import Encoding, PublicFormat

ALG = b"ED"
LEGACY_ALG = b"Ed"
KEY_ALG = b"Ed"
TRUSTED_PREFIX = "trusted comment: "


def make_keypair(seed):
    priv = Ed25519PrivateKey.from_private_bytes(seed)
    pk = priv.public_key().public_bytes(Encoding.Raw, PublicFormat.Raw)
    return priv, pk, hashlib.sha256(pk).digest()[:8]


def public_key_text(pk, key_id):
    body = base64.b64encode(KEY_ALG + key_id + pk).decode()
    return "untrusted comment: minisign public key: %s\n%s\n" % (key_id[::-1].hex().upper(), body)


def sign(message, priv, key_id, trusted_comment, legacy=False):
    digest = message if legacy else hashlib.blake2b(message).digest()
    sig = priv.sign(digest)
    global_sig = priv.sign(sig + trusted_comment.encode("utf-8"))
    alg = LEGACY_ALG if legacy else ALG
    return (
        "untrusted comment: signature from w2rpm test key\n"
        + base64.b64encode(alg + key_id + sig).decode() + "\n"
        + TRUSTED_PREFIX + trusted_comment + "\n"
        + base64.b64encode(global_sig).decode() + "\n"
    )


def _parse_public(text):
    lines = text.split("\n")
    if len(lines) < 2 or not lines[0].startswith("untrusted comment:") or any(lines[2:]):
        raise ValueError("bad public key file")
    raw = base64.b64decode(lines[1], validate=True)
    if len(raw) != 42 or raw[:2] != KEY_ALG:
        raise ValueError("bad public key")
    return raw[2:10], raw[10:]


def verify(message, sig_text, pubkey_text):
    try:
        key_id, pk = _parse_public(pubkey_text)
        lines = sig_text.split("\n")
        if (len(lines) < 4 or not lines[0].startswith("untrusted comment:")
                or not lines[2].startswith(TRUSTED_PREFIX) or any(lines[4:])):
            return False
        raw = base64.b64decode(lines[1], validate=True)
        if len(raw) != 74 or raw[:2] != ALG or raw[2:10] != key_id:
            return False
        sig = raw[10:]
        global_sig = base64.b64decode(lines[3], validate=True)
        key = Ed25519PublicKey.from_public_bytes(pk)
        key.verify(sig, hashlib.blake2b(message).digest())
        key.verify(global_sig, sig + lines[2][len(TRUSTED_PREFIX):].encode("utf-8"))
        return True
    except (ValueError, InvalidSignature):
        return False

"""Reference verifier for index.json + index.json.sig (docs/index.md). Returns "ok" or a reason code."""
import base64
import json
import re
from datetime import datetime, timezone
from urllib.parse import urlsplit

from . import jsonutil, minisign
from .manifest import ID_RE, SEMVER_RE, validate_manifest

MAX_INDEX_BYTES = 8 * 1024 * 1024
MAX_PACKAGE_BYTES = 64 * 1024 * 1024
MAX_PLUGINS = 1000
MAX_VERSIONS = 200
TIME_FORMAT = "%Y-%m-%dT%H:%M:%SZ"
TIME_RE = re.compile(r"^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$")
SHA256_RE = re.compile(r"^[0-9a-f]{64}$")

TOP_REQUIRED = {"schema", "serial", "generated", "expires", "plugins"}
TOP_OPTIONAL = {"next_key"}
PLUGIN_KEYS = {"id", "versions"}
VERSION_KEYS = {"version", "manifest", "url", "sha256", "size", "min_manager"}

REASONS = {
    "too_large", "bad_signature", "not_json", "duplicate_key", "bad_type", "unknown_field",
    "missing_field", "bad_schema", "bad_time", "rollback", "expired", "bad_key", "too_many",
    "bad_id", "duplicate", "bad_version", "bad_manifest", "mismatch", "bad_url", "bad_hash",
    "bad_size",
}


def _is_int(v):
    return isinstance(v, int) and not isinstance(v, bool)


def _keys(obj, required, optional=frozenset()):
    if set(obj) - required - optional:
        return "unknown_field"
    if required - set(obj):
        return "missing_field"
    return None


def _time(s):
    if not isinstance(s, str) or not TIME_RE.match(s):
        raise jsonutil.Reject("bad_time")
    try:
        return datetime.strptime(s, TIME_FORMAT).replace(tzinfo=timezone.utc)
    except ValueError:
        raise jsonutil.Reject("bad_time") from None


def _url_ok(u):
    if not isinstance(u, str) or len(u) > 2048 or not u.isascii() or any(c <= " " for c in u):
        return False
    try:
        p = urlsplit(u)
        return p.scheme == "https" and bool(p.hostname) and p.username is None and p.password is None
    except ValueError:
        return False


def _key_ok(k):
    try:
        raw = base64.b64decode(k, validate=True)
    except (ValueError, TypeError):
        return False
    return len(raw) == 42 and raw[:2] == minisign.KEY_ALG


def _check_version(plugin_id, v, seen):
    if not isinstance(v, dict):
        return "bad_type"
    err = _keys(v, VERSION_KEYS)
    if err:
        return err
    if not isinstance(v["version"], str) or not SEMVER_RE.match(v["version"]):
        return "bad_version"
    if not isinstance(v["min_manager"], str) or not SEMVER_RE.match(v["min_manager"]):
        return "bad_version"
    if v["version"] in seen:
        return "duplicate"
    seen.add(v["version"])
    manifest = v["manifest"]
    if not isinstance(manifest, dict):
        return "bad_manifest"
    if validate_manifest(json.dumps(manifest).encode("utf-8")) != "ok":
        return "bad_manifest"
    if manifest["id"] != plugin_id or manifest["version"] != v["version"]:
        return "mismatch"
    if not _url_ok(v["url"]):
        return "bad_url"
    if not isinstance(v["sha256"], str) or not SHA256_RE.match(v["sha256"]):
        return "bad_hash"
    if not _is_int(v["size"]):
        return "bad_type"
    if not 1 <= v["size"] <= MAX_PACKAGE_BYTES:
        return "bad_size"
    return None


def _check_plugins(plugins):
    if not isinstance(plugins, list):
        return "bad_type"
    if len(plugins) > MAX_PLUGINS:
        return "too_many"
    seen_ids = set()
    for p in plugins:
        if not isinstance(p, dict):
            return "bad_type"
        err = _keys(p, PLUGIN_KEYS)
        if err:
            return err
        pid = p["id"]
        if not isinstance(pid, str) or not ID_RE.match(pid):
            return "bad_id"
        if pid in seen_ids:
            return "duplicate"
        seen_ids.add(pid)
        versions = p["versions"]
        if not isinstance(versions, list) or not versions:
            return "bad_type"
        if len(versions) > MAX_VERSIONS:
            return "too_many"
        seen = set()
        for v in versions:
            err = _check_version(pid, v, seen)
            if err:
                return err
    return None


def verify_index(index_raw, sig_text, pubkey_text, cached_serial, now):
    if len(index_raw) > MAX_INDEX_BYTES:
        return "too_large"
    if not minisign.verify(index_raw, sig_text, pubkey_text):
        return "bad_signature"
    try:
        doc = jsonutil.parse(index_raw)
        if not isinstance(doc, dict):
            return "bad_type"
        err = _keys(doc, TOP_REQUIRED, TOP_OPTIONAL)
        if err:
            return err
        if not _is_int(doc["schema"]) or doc["schema"] != 1:
            return "bad_schema"
        if not _is_int(doc["serial"]) or doc["serial"] < 0:
            return "bad_type"
        generated, expires = _time(doc["generated"]), _time(doc["expires"])
    except jsonutil.Reject as r:
        return r.code
    if generated > expires:
        return "bad_time"
    if doc["serial"] < cached_serial:
        return "rollback"
    if expires <= now:
        return "expired"
    if "next_key" in doc and not (isinstance(doc["next_key"], str) and _key_ok(doc["next_key"])):
        return "bad_key"
    return _check_plugins(doc["plugins"]) or "ok"
```

    """4 bytes in wire order; all zero when `plugins` is empty. Input: enabled affects_simulation plugins."""
    ids = [p["id"] for p in plugins]
    if len(set(ids)) != len(ids):
        raise ValueError("duplicate plugin id")
    if not plugins:
        return b"\x00\x00\x00\x00"
    h = hashlib.sha256()
    for p in sorted(plugins, key=lambda p: p["id"].encode("utf-8")):
        h.update(p["id"].encode("utf-8") + b"\x00")
        h.update(p["version"].encode("utf-8") + b"\x00")
        h.update(bytes.fromhex(p["sha256"]))
    return h.digest()[:4]


def peer_tag(plugin_id):
    return hashlib.sha256(plugin_id.encode("utf-8")).digest()[:4]
```

```c
/*
 * w2rpm plugin ABI, version 1. ADD-ONLY: fields are only ever appended to the end of a struct,
 * enum values are never renumbered, nothing is removed. See docs/abi.md for limits and rules.
 *
 * Threading: every host function and every plugin callback runs on the game's main thread.
 * Capabilities are a consent prompt and a guardrail, not a sandbox: a native plugin runs in the
 * game process and can do anything that process can.
 */
#ifndef W2R_ABI_H
#define W2R_ABI_H

#include <stddef.h>
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

#define W2R_ABI_VERSION 1u

#if defined(_WIN32)
#define W2R_CALL __cdecl
#define W2R_EXPORT __declspec(dllexport)
#else
#define W2R_CALL
#define W2R_EXPORT __attribute__((visibility("default")))
#endif

/* ---- status codes ---------------------------------------------------------------------- */
typedef int32_t W2rStatus;
enum {
    W2R_OK = 0,
    W2R_E_DENIED = -1,      /* capability not approved */
    W2R_E_INVALID = -2,     /* bad argument, or access to game memory failed */
    W2R_E_LIMIT = -3,       /* a size or count limit was exceeded */
    W2R_E_STATE = -4,       /* not allowed right now (wrong thread, not in a lobby, ...) */
    W2R_E_UNSUPPORTED = -5, /* host does not provide this (older host) */
    W2R_E_NOT_FOUND = -6,
    W2R_E_RATE = -7,        /* rate limit hit; the call had no effect */
    W2R_E_CONFLICT = -8     /* hook overlaps an existing patch */
};

/* ---- value types ----------------------------------------------------------------------- */
/* UTF-8, NOT NUL-terminated. */
typedef struct W2rStr {
    const char *ptr;
    uint32_t len;
} W2rStr;

typedef struct W2rBuf {
    const uint8_t *ptr;
    uint32_t len;
} W2rBuf;

typedef uint32_t W2rHandle; /* host-issued, 0 is never valid */

enum { W2R_LOG_DEBUG = 0, W2R_LOG_INFO = 1, W2R_LOG_WARN = 2, W2R_LOG_ERROR = 3 };
enum { W2R_FILE_READ = 1, W2R_FILE_WRITE = 2 /* create or truncate */ };
#define W2R_SLOT_ALL 0xFFFFFFFFu /* peer_send: every peer that announced the handshake */

/* ---- limits (also in docs/abi.md) ------------------------------------------------------ */
#define W2R_MAX_LOG_BYTES 512u
#define W2R_MAX_SETTING_KEY 64u
#define W2R_MAX_SETTING_STR 1024u
#define W2R_MAX_FILE_NAME 64u
#define W2R_MAX_IO_BYTES 65536u
#define W2R_MAX_SYMBOL_NAME 64u
#define W2R_MAX_READ_BYTES 4096u
#define W2R_MAX_CHAT_BYTES 200u
#define W2R_PEER_HEADER_BYTES 9u   /* 0xE7 'W' '2' 'R' 'P' tag[4] */
#define W2R_MAX_PEER_PAYLOAD 960u

/* ---- events ---------------------------------------------------------------------------- */
typedef uint32_t W2rEventId;
enum {
    W2R_EVT_LOBBY_ENTER = 1,
    W2R_EVT_LOBBY_LEAVE = 2,
    W2R_EVT_LOBBY_PLAYER_JOIN = 3,  /* payload W2rEvtPlayer; name empty without chat.read */
    W2R_EVT_LOBBY_PLAYER_LEAVE = 4, /* payload W2rEvtPlayer */
    W2R_EVT_CHAT_RECEIVED = 5,      /* payload W2rEvtChat; needs chat.read */
    W2R_EVT_PEER_MESSAGE = 6,       /* payload W2rEvtPeerMessage; needs net.send */
    W2R_EVT_MATCH_START = 7,
    W2R_EVT_MATCH_END = 8,
    W2R_EVT_SETTINGS_CHANGED = 9,
    W2R_EVT_SHUTDOWN = 10
};

typedef struct W2rEvent {
    uint32_t struct_size;
    W2rEventId id;
    const void *payload; /* NULL for events without one; valid only during the callback */
} W2rEvent;

typedef struct W2rEvtPlayer {
    uint32_t struct_size;
    uint32_t net_slot;
    W2rStr name; /* sanitised: printable ASCII only */
} W2rEvtPlayer;

typedef struct W2rEvtChat {
    uint32_t struct_size;
    uint32_t net_slot;
    W2rStr name;
    W2rStr text; /* sanitised: printable ASCII only */
} W2rEvtChat;

typedef struct W2rEvtPeerMessage {
    uint32_t struct_size;
    uint32_t net_slot; /* the slot the transport reported, never one named inside the message */
    W2rBuf data;       /* the payload after the 9-byte header */
} W2rEvtPeerMessage;

/* ---- UI (only valid inside on_ui) ------------------------------------------------------ */
typedef struct W2rUi {
    uint32_t struct_size;
    void *ctx;
    void (W2R_CALL *label)(void *ctx, W2rStr text);
    int32_t (W2R_CALL *button)(void *ctx, W2rStr text);           /* 1 when pressed */
    int32_t (W2R_CALL *checkbox)(void *ctx, W2rStr text, int32_t *value); /* 1 when changed */
    int32_t (W2R_CALL *slider_int)(void *ctx, W2rStr text, int32_t *value, int32_t min, int32_t max);
} W2rUi;

/* ---- host table: provided by the host, one instance per plugin ------------------------- */
typedef struct W2rHost {
    uint32_t struct_size; /* check before using any field past the version you built against */
    uint32_t abi_version;
    void *token;          /* opaque; pass back as the first argument of every call */

    /* log (implicit) */
    W2rStatus (W2R_CALL *log)(void *token, uint32_t level, W2rStr msg);

    /* settings (implicit): the plugin's own settings only */
    W2rStatus (W2R_CALL *settings_get_i64)(void *token, W2rStr key, int64_t *out);
    W2rStatus (W2R_CALL *settings_set_i64)(void *token, W2rStr key, int64_t value);
    W2rStatus (W2R_CALL *settings_get_str)(void *token, W2rStr key, char *buf, uint32_t cap,
                                           uint32_t *len_out);
    W2rStatus (W2R_CALL *settings_set_str)(void *token, W2rStr key, W2rStr value);

    /* fs.data (implicit): flat files in the plugin's own data folder, by host handle */
    W2rStatus (W2R_CALL *data_open)(void *token, W2rStr name, uint32_t flags, W2rHandle *out);
    W2rStatus (W2R_CALL *data_read)(void *token, W2rHandle file, void *dst, uint32_t cap,
                                    uint32_t *read_out);
    W2rStatus (W2R_CALL *data_write)(void *token, W2rHandle file, const void *src, uint32_t len);
    W2rStatus (W2R_CALL *data_close)(void *token, W2rHandle file);

    /* events */
    W2rStatus (W2R_CALL *subscribe)(void *token, W2rEventId id);
    W2rStatus (W2R_CALL *unsubscribe)(void *token, W2rEventId id);

    /* game.read */
    W2rStatus (W2R_CALL *symbol_lookup)(void *token, W2rStr name, W2rHandle *out);
    W2rStatus (W2R_CALL *symbol_read)(void *token, W2rHandle symbol, uint32_t offset, void *dst,
                                      uint32_t len);

    /* chat.write */
    W2rStatus (W2R_CALL *chat_send)(void *token, W2rStr text);

    /* net.send */
    W2rStatus (W2R_CALL *peer_send)(void *token, uint32_t net_slot_or_all, W2rBuf payload);

    /* hooks.raw (dangerous) */
    W2rStatus (W2R_CALL *hook_install)(void *token, uint32_t target, void *detour, void **original_out,
                                       W2rHandle *out);
    W2rStatus (W2R_CALL *hook_remove)(void *token, W2rHandle hook);
} W2rHost;

/* ---- plugin table: returned by the plugin ---------------------------------------------- */
typedef struct W2rPlugin {
    uint32_t struct_size;
    W2rStatus (W2R_CALL *on_load)(const W2rHost *host);   /* non-zero fails the load (E_LOAD) */
    void (W2R_CALL *on_event)(const W2rEvent *event);     /* may be NULL */
    void (W2R_CALL *on_ui)(const W2rUi *ui);              /* may be NULL */
    void (W2R_CALL *on_unload)(void);                     /* may be NULL; best effort */
} W2rPlugin;

/* The single export every plugin DLL provides. */
typedef const W2rPlugin *(W2R_CALL *W2rPluginMain)(const W2rHost *host);
W2R_EXPORT const W2rPlugin *W2R_CALL w2r_plugin_main(const W2rHost *host);

#ifdef __cplusplus
}
#endif

#endif /* W2R_ABI_H */
```
